# Прямой источник

Русскоязычный каталог полезных программ с прямыми ссылками на официальные сайты и репозитории разработчиков.

**Сайт:** https://karaskiras.github.io/direct-source/

Задача проекта — сократить путь от «мне нужна программа» до её первоисточника. Каталог не хранит установщики, не использует рекламные редиректы, стороннюю аналитику, внешние шрифты или CDN. Все 12 карточек доступны и без JavaScript. Поиск и фильтры работают локально в браузере.

## Что внутри

- Доступ к сети: zapret-discord-youtube (сборка Flowseal), Happ Proxy Utility.
- Браузер: Firefox.
- Файлы и система: 7-Zip, LocalSend, Everything, Rufus.
- Пароли: KeePassXC.
- Документы: LibreOffice.
- Медиа: VLC, OBS Studio, ShareX.

[Таблица с официальными ссылками](CATALOG.md) · [Данные и основания проверки](catalog.json)

Happ — прокси-клиент, которому нужен отдельный сервер или подписка. zapret — инструмент работы с DPI-фильтрацией, не VPN и не средство анонимизации.

## Как проверяются источники

Для каждой записи фиксируются адрес проекта, дата ручной проверки и страница-основание. При смене домена ищем ссылку с прежнего официального сайта. У сборки указываем автора и исходный проект. Ответ HTTP 200 сам по себе не доказывает подлинность сайта.

Проверка источника не означает аудит кода или установщика. Доступность зависит от сети и региона; мы не измеряли её у российских провайдеров. Не публикуем неподтверждённые обвинения в адрес браузеров, поисковиков и разработчиков.

Первичная проверка ссылок: **4 октября 2026 года**. Она не обновляется автоматически. Каталог требует периодической ручной перепроверки, особенно при смене владельца или домена.

## Добавить программу

Создайте issue или pull request. Укажите название, назначение, платформы, официальный адрес и доказательство принадлежности адреса проекту. Предпочитаем программы с понятным авторством и распространением. Сторонние зеркала, репаки, сокращатели и партнёрские ссылки не принимаются.

Редактируйте `catalog.json`, затем выполните:

```sh
npm run build
npm start
```

Нужен Node.js 18 или новее. Устанавливать npm-зависимости не требуется. Сборка проверяет обязательные поля, платформы, уникальность идентификаторов и HTTPS-адреса; она не проверяет доступность ссылок по сети.

Откройте http://127.0.0.1:4173/direct-source/ . Коммитьте `catalog.json`, обновлённые файлы `docs/` и `CATALOG.md` вместе. Для изменения оформления редактируйте `src/` и повторите сборку.

## GitHub Pages

Источник публикации: **Settings → Pages → Deploy from a branch → main → /docs**. Папка `docs` содержит готовый статический сайт. GitHub Pages публикует её при изменениях ветки. Пути к CSS, JS и иконке относительные, поэтому сайт работает по адресу репозитория.

## Дальнейшее развитие

Кандидаты на отдельную проверку перед добавлением: Bitwarden (синхронизация паролей), Thunderbird (почта), SumatraPDF (чтение PDF), PowerToys (инструменты Windows), GIMP и Krita (изображения), RustDesk (удалённый доступ). Для каждого сначала нужно подтвердить официальный источник, платформы и ограничения.

Полезные следующие функции: история смены источников и проверка битых ссылок в GitHub Actions с ручным разбором результатов. Автоматическая проверка доступности не должна проставлять отметку «безопасно».

Названия программ принадлежат их правообладателям. Проект не аффилирован с перечисленными разработчиками.
